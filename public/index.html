🚗 Vehicle Endpoints
GET/Welcome, author info & endpoint list
GET/vehiclesList all vehicles
GET/vehicles/:idGet one vehicle — 404 if not found
GET/vehicles/search?q=&location=&category=&available=🎁 Bonus: search with query params
GET/vehicles/category/:nameFilter by category — optional param
GET/vehicles/files/*pathNamed wildcard — returns path segments
POST/vehiclesAdd vehicle — 400 if missing fields
PUT/vehicles/:idUpdate vehicle — 404 if not found
DELETE/vehicles/:idDelete vehicle 🔒 requires auth token

GET/owners/:idGet one owner — 404 if not found
GET/owners/search?q=&city=&verified=Search owners
GET/owners/city/:nameFilter owners by city
POST/ownersRegister new owner — 400 if missing fields
PUT/owners/:idUpdate owner
DELETE/owners/:idRemove owner 🔒 requires auth token
