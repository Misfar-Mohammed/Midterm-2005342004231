📖 Available Endpoints

GET/Welcome & endpoint list
GET/booksGet all books
GET/books/:idGet book by ID
GET/books/search?q=Search books by title/author
GET/books/category/:genreFilter by genre
GET/books/files/*pathServe book files (wildcard)
POST/booksCreate a new book 🔒
PUT/books/:idUpdate a book 🔒
DELETE/books/:idDelete a book 🔒
GET/authorsGet all authors
GET/authors/:idGet author by ID
POST/authorsCreate author 🔒
PUT/authors/:idUpdate author 🔒
DELETE/authors/:idDelete author 🔒
